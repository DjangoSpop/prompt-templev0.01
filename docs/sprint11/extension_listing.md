# Chrome Web Store listing — Prompt Temple (brand v2 voice)

**Title (≤45):** Prompt Temple: clearer prompts, saved

**Summary (≤132):** Save every prompt you write, make it clearer in one click, and paste proven prompts into ChatGPT, Claude and Gemini.

**Description (~150 words):**

Prompt Temple keeps the prompts you write and helps you write better ones.

Inside ChatGPT, Claude or Gemini, every prompt you send is saved to your library, so a good one is never lost. When a prompt is rough, one click makes it clearer: we add the role, the context, the format and the constraints the model needs, and show you what changed, so you learn as you go.

Need a starting point? Open the library of licensed prompts, each shown with what it actually produces, and paste one into the chat with a single tap. Fill in the variables first if the prompt has them.

Your prompts stay in your account. The extension asks only for the tabs it works in. Free to start, nothing to configure.

Made for people who ask AI for real work and want the answer to come back right the first time.
